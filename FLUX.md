# Flux

Le flux v0 = tirer → lier → `etat()`.

```
quelle.py tirer     →  .quelle.json   (source=os sur cell)
unforge quelle-lier →  data/quelle.json  (hors git)
etat()              →  {source, simule, sha256}
```

Quand un QRNG/QKD répondra, `tirer --source qrng` cessera de refuser.
Jusque-là le flux est `os`. C'est le terrain, pas le décor.
